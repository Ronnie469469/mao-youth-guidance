# Knowledge base v1

This is the active v1 knowledge base. `thought-cards.json` contains user-approved conceptual cards, `concept-relations.json` contains the approved graph snapshot, and `passages.jsonl` contains the retrieval corpus. Passage records remain quote-unverified unless their individual `quote_status` is changed after page-level checking, so they may support search and paraphrase but not verbatim quotation.
