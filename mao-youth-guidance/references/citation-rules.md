# Citation rules

Use this order where known:

`《作品名》, 日期, 版本/卷次, PDF 编号, 页码或段落`

Keep verbatim quotations short. In the guidance sheet, a quote must point to a `quote_verified` passage. In the long commentary, prefer paraphrase plus an attribution; include only a few short verified quotations. Do not put quotation marks around a paraphrase. Never write that Mao held a view about a current event unless a direct contemporaneous source exists; normally write that a method or concept is being applied today.

Read quotations only from `verified-quotes.jsonl`. Reproduce `quote_text` exactly and include its work, volume, PDF ID, filename, page, paragraph, language, and edition/date fields when known. Do not quote `verified_text` directly, splice adjacent passages, silently modernize punctuation, or translate a Japanese/English record and present it as Chinese original text.

If retrieval finds only `paraphrase_only` material, say that the current material has not passed verbatim verification and provide a clearly marked paraphrase without quotation marks. Ignore every passage listed in `blocked-passages.jsonl`.
